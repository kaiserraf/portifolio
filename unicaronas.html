GET /desafio

O problema

O UniCaronas surgiu a partir de três problemas identificados entre os estudantes: muitos alunos precisavam se deslocar até a faculdade, mas moravam em regiões com difícil acesso ao transporte público; outros não possuíam veículo próprio; e, mesmo aqueles que possuíam, enfrentavam longas filas e congestionamentos nos horários de pico na UniBrasil. Diante desse cenário, foi idealizado o UniCaronas como uma solução para facilitar o deslocamento dos estudantes e conectar aqueles que ofereciam e precisavam de caronas.

Decisões técnicas e aprendizados

// bug — CORS

Depurei uma configuração de CORS que bloqueava as requisições do frontend em ambiente de desenvolvimento, entendendo na prática como origin, métodos e headers permitidos se relacionam.

// bug — seed de dados

Identifiquei corrupção de hash bcrypt nos dados de seed do banco, o que impedia logins de teste — reforçou a importância de gerar hashes em tempo de execução, não copiar valores fixos.

// arquitetura — desenho de sistema

Aprendi regras para desenhar uma arquitetura de sistema, e a lógica existente por trás.

// arquitetura — chat

Desenhei a arquitetura do chat em tempo real, incluindo notificações de pedido de carona para motoristas, e comparei na prática Socket.io contra uma versão via polling.
